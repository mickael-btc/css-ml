A tiny desktop run by one network

Three windows and a dock. Every click goes through one neural network that decides what happens to every window, in CSS, with 0 bytes of JavaScript.

  • The window manager: which windows are open, minimized or full screen, where each one sits, and which is on top. That is 20 numbers. Each click hands them, plus the click, to one network of 362 neurons, which returns the 20 new numbers.
  • One click, one run: the page chains that same network 40 times, once per click, so you get 40 clicks. Reset starts over. Buttons that would change nothing, like an arrow at the edge of the desktop or the window that is already in front, are switched off, so they don't use up a click.
  • The motion is plain CSS: the network decides where a window should be; the browser only animates it there.
  • Notes is a real text box: what you type is kept by the browser, not by the network, so it stays while windows move.
  • Try: click a window that is behind another to bring it forward, nudge it with the arrows, send it to the dock and back, open a photo, and watch the numbers in Monitor.

How it works (for the curious)

Where this comes from

A reduced, CSS edition of Cheng Lou's HandwiredOS, a desktop whose windows, dock and apps are run by one compiled program. CSS can't read where the pointer is, which key you pressed or what time it is, so this edition is driven by clicks only: every click is one event. You can't drag a window; the arrows move it one step on a coarse grid. Typing goes to a normal text box the network never sees.

A second, smaller network (3 layers, 168 neurons) turns the final 20 numbers into what you see: each window's rectangle (full screen when maximized), whether it is on screen, which one is focused, which photo shows, the arrows that can still move. CSS then only places boxes at those numbers, with a transition.

Each of the 40 slots is its own group of 37 radio buttons, and every control on screen holds 40 labels, one per slot, of which only the next slot's is shown. A window's title bar and its inside are two labels for the same click. That's 1,600 labels in all.

Checked in numpy against a plain Python window manager: every event in every combination of window flags, stacking order and photo (285,000 cases), every event at every grid position, and 4,000 random sequences of 60 events, every value after every event. The browser test clicks 2 scripted and 6 random 40-click sequences in Chromium, Firefox and WebKit, on a wide screen and at phone width, compares the whole state after every click, and checks that switched-off buttons and the keyboard change nothing.
