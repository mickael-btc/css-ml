Handwired

Normal code, turned into a neural network. Then networks that run other networks. All in CSS, with 0 bytes of JavaScript.

  • A neural network is just thousands of tiny steps of “add these numbers, and if the result is negative, use 0”.
  • That's enough to write rules. “Is this square free?” or “did someone win?” each become a few of those steps. So code can become a network, with no training.
  • And a network can run another network, if you give it that network's numbers: like a console and its cartridge.
  • Idea from Cheng Lou's handwired. Each page is tested to give exactly the same answers as Python, in Chrome, Firefox and Safari.

How it works (for the curious)

The compiler

handwired/scripts/hw.py is about 450 lines. A program is built from inputs, constants, +, constant × and relu; helpers give integer logic (ge, eq, AND, OR, gating, a lexicographic argmax). compile() places each ReLU at 1 + the depth of its deepest input, carries values that are needed further down through identity units, and returns an ordinary layered integer MLP. The same net runs in numpy, and to_css() writes it out as registered @property integers.
