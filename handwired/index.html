Handwired

Regular code, rewritten as a neural network. Ideas from Cheng Lou's handwired: an if becomes ReLUs, (a > 4) ? 10 : 12 becomes above4 = relu(a − 4) − relu(a − 5), above4·10 + (1 − above4)·12. No training, exact, and still differentiable.

Here it meets the rest of this repo, where networks run in the browser's style engine. Every page is pure CSS, 0 bytes of JavaScript, and each one is tested to match its Python reference exactly in Chromium, Firefox and WebKit.

The compiler

handwired/scripts/hw.py is about 450 lines. A program is built from inputs, constants, +, constant × and relu; helpers give integer logic (ge, eq, AND, OR, gating, a lexicographic argmax). compile() places each ReLU at 1 + the depth of its deepest input, carries values that are needed further down through identity units, and returns an ordinary layered integer MLP. The same net runs in numpy, and to_css() writes it out as registered @property integers.
