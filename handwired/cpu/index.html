A computer made of neurons

A tiny 8-bit computer where one tick of the clock is one neural network. It runs real programs, in CSS, with 0 bytes of JavaScript.

  • The computer: one number in its hand (A), 8 numbers of memory, a list of 16 instructions, and a printer. Like a 1970s kit computer.
  • One tick is one network of 811 neurons: read the next instruction, do it (add, subtract, store, jump…), move on. The page runs that same network 128 times in a row.
  • The program is data, like the cartridge on the Swap the brain page: the network never changes, the program does.
  • Try: pick a program and change its inputs, or press Write your own and change any of its 16 lines. Read what it printed; below, every tick the computer made.

Checked in numpy against a plain Python emulator: the demo programs with every input, the editor's default, 1,000 random programs of the kind the editor can make and 3,000 random programs of any kind, all 128 ticks, every register at every tick. The browser tests run the demo programs in Chromium, Firefox and WebKit, and type programs into the editor with real clicks (random ones, and edge cases: a jump to itself, writing every memory cell, sums that wrap past 255, printing more than 16 times, stopping on line 0), comparing every tick's A and the final state with an emulator written in the test.

Writing your own

The editor is 560 radio buttons: for each of the 16 lines, one per instruction (11) and one per number (16), and 16 for each of the 8 starting memory cells. Each picked radio sets one integer on the page (.app:has(#eop3_7:checked) { --eop3: 7 }), and picking Write your own copies those integers into the program inputs of the same network every other cartridge uses. The network does not change at all: the program is just 32 more numbers it reads.

Numbers stop at 15 to keep the page small (the network itself takes any argument up to 255). Memory addresses use the number mod 8 and jumps use it mod 16, so ST 9 writes cell 1. There is no "do nothing" instruction, but ADDI 0 is one. Each line's text (LD 3, "A = memory[3]") is drawn from the same integers: the numbers with CSS counters, and the instruction name and its sentence by showing one of 11 stacked words and hiding the rest.
