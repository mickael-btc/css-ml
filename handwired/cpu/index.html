A computer made of neurons

A tiny 8-bit computer where one tick of the clock is one neural network. It runs real programs, in CSS, with 0 bytes of JavaScript.

  • The computer: one number in its hand (A), 8 numbers of memory, a list of 16 instructions, and a printer. Like a 1970s kit computer.
  • One tick is one network of 811 neurons: read the next instruction, do it (add, subtract, store, jump…), move on. The page runs that same network 128 times in a row.
  • The program is data, like the cartridge on the Swap the brain page: the network never changes, the program does.
  • Try: pick a program, change its inputs, and read what it printed. Below, every tick the computer made.

How it works (for the curious)

The instructions

CodeDoesCodeDoes
HLTstopADDI nA = A + n
LDI nA = nJMP tgo to instruction t
LD mA = memory[m]JZ tgo to t if A is 0
ST mmemory[m] = AJNZ tgo to t if A is not 0

One tick, as ReLUs

PartHow
fetch[PC = i] for every line i, each gating that line's opcode and argument: relu(op_i − 15·(1 − [PC = i]))
decode[op = k] for each opcode, AND not halted
addressarg mod 8 = arg − 8·round(relu(2·arg − 7) / 16), one integer unit
ALUA + m, A − m, A + n, each wrapped with one comparison: s − 256·[s ≥ 256]
